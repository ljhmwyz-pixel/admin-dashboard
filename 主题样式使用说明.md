# 主题样式配置文档

## 一、基础配置

```scss
// scss文件头部引入
@use '@/shared/styles/variables' as *;
@use '@/shared/styles/mixins' as *;
@use 'sass:color';

// 基础背景色
background-color: $color-bg-base;
@include dark-theme {
  background-color: $dark-color-bg-base;
}

// 容器背景色
background-color: $color-bg-container;
@include dark-theme {
  background-color: $dark-color-bg-container;
}

// 主文本（透明度 1）
color: $color-text-primary;
@include dark-theme {
  color: $dark-color-text-primary;
}

// 次文本（透明度 0.6）
color: $color-text-secondary !important;
@include dark-theme {
  color: $dark-color-text-secondary;
}

// 例如：
.label {
  display: flex;
  align-items: center;
  gap: 10px;
  font-size: 14px;
  line-height: 14px;
  font-weight: 500;
  color: $color-text-secondary;
  @include dark-theme {
    color: $dark-color-text-secondary;
  }
}
```
